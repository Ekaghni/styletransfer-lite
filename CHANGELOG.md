# Changelog

## 0.1.0
- First release. 26 built-in styles with blending, strength and colour preservation.
- Any image as a style (Magenta arbitrary stylization models).
- CLI with folder batch, stdin/stdout and `--json`; Python API; tkinter GUI; video and webcam commands.
- Models converted to ONNX so the install needs only numpy, Pillow and onnxruntime.
